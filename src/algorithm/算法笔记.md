# 数组

## 二分查找

注意事项：

* 确定好查找区间。`[left、right] `或` [left、right）`
* 确定好边界条件。 `left <= right` 或 `left < right` 
* `middle`的求法 不要用`(left+right)/2` 用`left+(right-legt)/2`
* `>>1`等同于对正整数向下取整除以2。
